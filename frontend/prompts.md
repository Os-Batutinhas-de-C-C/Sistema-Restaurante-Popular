# Prompts para o Agente

## Implementar uma spec
- Leia a base do projeto dentro de `src/app/` para entender a estrutura utilizada.
- Leia `AGENTS.md` antes de executar as specs.
- Implemente `specs/<id-nome>`.  Antes de codar, apresente um plano de desenvolvimento. 

## Revisar uma implementação
- Revise o que foi implementado comparando com `specs/<id-nome-anterior>`.  Liste os problemas antes de alterar qualquer código.
